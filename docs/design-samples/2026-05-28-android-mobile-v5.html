§ 2Brief· Three pages

one verb, one surface.

An Arduino IDE for the phone is a strange thing to want. Cables are for desks, and phones are for elsewhere — which is the point. The bench is wherever the board is. A vehicle bay, a hangar floor, the back of a Land Cruiser on the perimeter. The IDE follows.

The brief is small. Five screens. One verb each. Sketch. Edit. Probe. Pick. Observe. The trick is the same as it was on the desktop — keep the chassis quiet so the operator can hear the board.

This document fixes the form. One typeface — JetBrains Mono, the language of the thing it edits. Weights from one hundred to eight hundred. Italics where the verb is. The chassis is warm graphite, the ink is warm cream, and there is no other colour. Status is communicated by inversion, not hue.

What is hidden is as important as what is shown. No gradients. No grain. No atmosphere. The page is a source file. The screen is its photograph. The type does the work.

U2 Editor · core surface 340 × 720

edit.

The primary surface. Tabs, gutter, source. Pin literals matching the connected board's pinmap pick up a thin hairline ring — tap one to open the probe. The active line inverts: cream block, dark text. The flash button reads as a verb, not a chip.

01pin literal
auto-recognised.
Numeric literals that match an entry in the connected board's pinmap get a one-pixel cream ring. Tap to open Probe.
02active line
inversion, not rule.
Cursor row inverts entirely — cream block, dark text. Replaces every hover state from the desktop with a single language of selection.
03flash
verb, in italic.
The only inverted surface that isn't a selection is the action verb itself. Italic, lowercase. Saturation is communicated by typography, not by colour.
04target
always visible.
Board ID, transport, baud — printed under the verb in mono small caps. Operator never has to ask "what am I writing to".
U3 Sketches · entry 320 × 680

sketch.

Sketchbook. A breathing dot for the linked board, a list keyed by reference designator (SK1, SK2…) — the same indexing convention used on the board itself. Selected sketch inverts. New sketch is a block at the foot.

01refdes
SKn, like the board.
Sketches carry reference designators in the gutter — same convention as silkscreen on a PCB. Tools should speak the language of their domain.
02state
by typeface.
"flashed" is italic, "draft" is regular. State is read; not coloured.

U4 Probe · live pinout 320 × 680

probe.

The board, rendered in box-drawing characters — the same language as a netlist printout. The active pin is a ★. Pin name in heavy italic below; the function in body. An IDE for embedded code, rendered in the typeface of embedded code.

01diagram
ASCII PCB.
Box-drawing characters render the board in monospaced columns. The diagram exports as text — paste it in a serial log; it still reads. This is the move.
02active pin
a star, not a glow.
The active pin is rendered as ★. Pulses through opacity, not colour. Type-led signal. No CSS gradient required.
U5 Boards · select transport 320 × 680

pick.

USB and WiFi share one surface. Selected device inverts entirely — black ink on cream. No checkmark, no chip, no fill — the row itself becomes the signal.

01selection
row, inverted.
Selected device is a cream block. No indicator badge — the whole row is the indicator.
02identity
VID:PID, not "Device".
Hardware addresses are surfaced in mono. Operator never has to translate "Device 3" into reality.

U6 Monitor · serial 320 × 680

observe.

Live serial. The "LIVE" pill is inverted; level codes (INF, DBG, WRN) carry weight rather than colour. Italic for warnings. The cursor breathes via opacity. Reading is primary; sending is below the fold.

01level
by weight, by case.
INF is regular. DBG is muted. WRN is italic. ERR is heavy italic. Level is encoded in the typeface itself.
02cursor
breathing, not blinking.
Opacity oscillation at 1.1s. Calmer than a hard blink; reads as alive without demanding attention.
