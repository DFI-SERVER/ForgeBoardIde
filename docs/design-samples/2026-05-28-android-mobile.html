An IDE for hardware,
shaped for the hand.

ForgeBoard's Android client takes the desktop workflow — write, compile, flash, observe — and rebuilds it around one thumb, a USB-C cable, and a board on the bench. Monochrome cool-slate, a single warm amber for intent, and one moment of theatre per screen.

01 / Restraint

Monochrome with one accent

Cool-slate surfaces, near-white type, amber reserved for primary intent. The screen never argues with itself.

02 / Tactility

Touch targets ≥ 44 px, always

FAB, tool buttons, list rows, soft-keyboard accessory — every interactive surface sized for the worst-case thumb.

03 / Theatre

One moment per screen

The pinout panel breathing under a finger. The compile wave. The connection dot. Small, but unmistakably ForgeBoard.

04 / Continuity

Same code, different shell

Preact components ride into the Tauri Android shell. The desktop tokens are reused, retuned for the small screen.
